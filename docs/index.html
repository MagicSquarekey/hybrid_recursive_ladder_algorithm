Query planning for bucket-limited time-series APIs

Aggregate long ranges with a handful of requests, not thousands.

A per-bucket client pays one network round trip per output row. The Hybrid Recursive Ladder decomposes a range into complete calendar units, fetches each level once at the next finer aggregation, and folds locally—so the request count depends on the coarse units, not the minute buckets.

The 139-second query

A production ThingsBoard query over a VPN took 139 seconds for 1,140 statistical buckets. The arithmetic was trivial; the network was not. Each bucket needed up to four HTTP calls.

The obvious fixes—one coarse interval, pre-aggregation, pagination—all sacrifice something: output resolution, write access to the source, or the number of round trips.

The useful question: can the source return a coarser or finer aggregation over a contiguous run, so one request fills many output units? 

2026-01-01 → 2026-10-21

hour    Oct 21 00–17      18
minute  Oct 21 18:00–18:48 49

423,049 minute buckets avoided

How it works

1

Decompose

Split the range into complete calendar units. Emit only complete units; push partial left and right edges to the next finer level.

2

Fetch once per level

Fetch each maximal contiguous run sharing a fetch level at the next finer aggregation: months as days, days as hours, hours as minutes.

3

Fold locally

Sum the returned buckets into the output units. Optionally split against local coverage and fetch only the uncovered sub-ranges.

What it is—and is not

It is a query-planning composition

  • calendar hierarchy as the query plan, not just the display bucket;
  • next-finer fetch plus local fold;
  • fetch-level + contiguity grouping;
  • coverage-aware gap filling;
  • request count bounded by the source's per-request bucket limit.

It is not a new database or a new theory

  • RRDtool / Whisper: multi-resolution archives;
  • BTrDB: hierarchical time-partitioned summaries;
  • TimescaleDB: hierarchical continuous aggregates;
  • Druid: calendar period granularity;
  • Prometheus / Grafana: point caps and single-step downsampling;
  • segment trees and timing wheels: aligned decomposition and level cascade.

The method is published as a public disclosure and released under the MIT License. The prior-art review documents the closest systems and the differences.
